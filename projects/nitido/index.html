PWA / Private local-first analysis

Nítido

A responsive PWA that turns CSV and OFX statements into useful financial reading, without asking the person to create an account.

Open live project ↗← Previous case
Role
Front-end product project
Stack
React, TypeScript, Vite, IndexedDB, Web Workers, Vitest, Playwright
Outcome
Private, offline-capable analysis with E2E coverage and CI/CD

Context

Bank statements contain useful answers, but they are difficult to read and too sensitive to hand over to an unknown server. Nítido makes the privacy model part of the interface.

Product decision

I designed an account-free flow that processes CSV and OFX files on-device, then turns raw transactions into categories and direct insights. The person can understand where the processing happens before importing data.
